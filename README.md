## ⚙️ How to Turn Off Watermarks in Google Gemini Settings

Google allows users to natively disable the visible watermark for future creations:

1. Go to **[gemini.google.com](https://gemini.google.com)** and sign in.
2. Click **Settings** (gear icon) in the bottom-left navigation bar.
3. Select **Media watermark**.
4. Switch the visible watermark toggle to **Off**.

> **Note:** This setting only applies to future creations. For existing downloaded media, use **[geminiremove.com](https://www.geminiremove.com)** to clean them losslessly.
